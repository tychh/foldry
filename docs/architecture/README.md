# Архитектурные решения Foldry

Эта папка содержит Architecture Decision Records (ADR) — короткие документы о
решениях, которые влияют на публичные форматы, границы компонентов и наблюдаемое
поведение Foldry.

## Статусы

- `Proposed` — решение обсуждается и еще может измениться.
- `Accepted` — решение обязательно для реализации.
- `Superseded` — решение заменено более новым ADR; старый файл сохраняется.
- `Deprecated` — решение больше не рекомендуется, но совместимость еще нужна.

Принятый ADR не редактируется так, чтобы незаметно изменить его смысл. Существенное
изменение оформляется новым ADR со ссылкой `Supersedes`. Уточнения, не меняющие
контракт, можно вносить в существующий документ с записью в разделе «История».

## Правило для новых вопросов

Если реализация обнаруживает неоднозначность, которая меняет публичный формат,
безопасность данных или ожидаемое поведение, работа над этим фрагментом
приостанавливается. Вопрос записывается в `notes/decisions.md`. После согласования
решение переносится в план и, если нужно, оформляется новым ADR.

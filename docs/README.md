## Documentation policy

Public documentation is English, describes the current product, and avoids
internal planning material. A behavior change is complete only when its tests and
the relevant user/developer documentation agree with the implementation.

## Project participation

Bug reports, usability feedback, and feature requests are welcome. Foldry does
not currently accept code contributions or pull requests. See the
[feedback and contribution policy](../CONTRIBUTING.md) before opening an issue.
